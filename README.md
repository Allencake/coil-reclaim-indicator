# coil-reclaim-indicator · 回踩确认

一套进出场规则写死的 TradingView 指标（Pine Script v5）。条件全部画在图上，能直接丢给 Grok Bot 或 Claude，让它按同一套规则帮你改、帮你接提醒。

## 规则

1. 大周期定方向：默认 60 分钟收盘在 EMA55 上方只做多，下方只做空。
2. 找压缩：布林带宽落到最近 100 根的 20% 分位以下，记为压缩区间，冻结高低点。
3. 等突破：放量收盘突破压缩区间，方向必须和大周期一致。
4. 等回踩：价格回踩突破位，并收在方向一侧，RSI 没有超买或超卖，才给进场标记。
5. 止损放在压缩区间极值外侧，第一目标按 1.5 倍风险标记（参数可改）。

## 上手

1. 打开 TradingView，底部 Pine Editor，新建指标。
2. 把 `coil_reclaim.pine` 全部粘进去，保存，添加到图表。
3. 在设置里调大周期、压缩分位、放量倍数等参数。
4. 需要提醒的话，新建警报，条件选这个指标的进场信号。
5. 把 `prompts/grok-bot.md` 里的提示词和图表截图一起丢给 Grok Bot 或 Claude，让它按这套规则帮你复核信号、改参数。

## 说明

- 图上的价位、止损、目标都是按参数画出来的标记，不是收益承诺。
- 仓库没有回测胜率和盈亏数据，先自己在回放或模拟盘里看一段时间。
- 不构成投资建议。
